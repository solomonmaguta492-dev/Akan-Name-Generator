# Akan Name Generator

A simple web app that generates an Akan name based on a user’s birth date and gender.

## Features

- Enter your birth date
- Choose your gender
- View your traditional Akan name
- Clean and responsive user interface

## How to Use

1. Open the project folder in your browser.
2. Open the index.html file.
3. Select your birth date and gender.
4. Click the submit button to see your Akan name.

## Project Files

- index.html — the main structure of the web page
- style.css — the styling for the website
- script.js — JavaScript logic for generating the Akan name

## Technologies Used

- HTML
- CSS
- JavaScript
